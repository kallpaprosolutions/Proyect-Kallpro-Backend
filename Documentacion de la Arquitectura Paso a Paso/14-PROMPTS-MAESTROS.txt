   - Los RIDE PDF tienen layout two-column. Solución: función nextNumber(label, maxChars=80)
     que busca el label en el texto extraído y luego encuentra el primer número decimal dentro de maxChars chars
   - parseClaveAcceso(clave49digitos): extrae fecha(0-8), tipo(8-10), RUC(10-23), ambiente(23), estab(24-27), ptoEmi(27-30), secuencial(30-39)

   - parseXml(buffer): xml2js, nodo raíz factura/notaCredito/notaDebito/retencion
     codigoPorcentaje: 0=0%, 2=12%, 5=15%, 7=8%, 4=NO_OBJETO, 6=EXENTO

2. src/services/sri-document.service.ts:
   - uploadSriDocument(): parse → check @@unique[companyId,claveAcceso] → buscar supplier por ruc → findMatchingPO → create
   - findMatchingPO(): OC SENT/PARTIAL/DRAFT del mismo proveedor, confidence: ±1%=95, ±5%=80, ±10%=65, ±20%=50, else=40
   - confirmSriDocument(): registerMovement(IN) por cada item PRODUCTO con productId → update OC status
   - deleteSriDocument(): bloquear si CONFIRMED
   - rejectSriDocument, getSriDocuments, updateSriDocument, getSriKpis, getCatalogs

3. src/routes/sri-document.routes.ts:
   - multer memoryStorage, 10MB, PDF+XML only
   - IMPORTAR: import { authMiddleware } from '../middleware/auth.middleware'  ← nombre exacto
   - Rutas: POST /upload, GET /, GET /kpis, GET /catalogs, GET/:id, PATCH/:id, POST/:id/confirm, POST/:id/reject, DELETE/:id

4. Registrar en src/index.ts:
   app.use('/api/sri', sriDocumentRoutes)

5. prisma/seed-tax.ts: sembrar 6 tarifas IVA + 42 retenciones IR/IVA

6. Frontend src/api/sriDocuments.ts + SriDocumentsPage.tsx + SriDocumentReviewPage.tsx
